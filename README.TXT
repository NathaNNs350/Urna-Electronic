~~~~~~~~~~~~~~~~~~~~~~~~
URNA ELETRÔNICA EM JAVA!
~~~~~~~~~~~~~~~~~~~~~~~~

Este projeto é uma réplica não exata de uma urna eletrônica totalmente funcional
sem banco de dados ou salvamento local, funcionando apenas por sessões.

Caso queira rodar este projeto pelo Prompt de Comando (CMD / Command Prompt)
Vá ate a pasta onde você instalou este projeto (Se for pelo netbeans, provavelmente
é a pasta "dist"), e rode a linha de comando abaixo.

java -jar "urnaEletronica.jar"
